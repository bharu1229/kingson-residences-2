# Kingson Residences & Residential Lands Pvt Ltd

A professional real estate website for Kingson Residences, showcasing properties, apartments, residential lands, and luxury homes.

## 🏠 Features

- Professional property listings
- Property search and filtering
- Property details with gallery
- Agent profiles
- Enquiry management
- Contact form
- Admin panel
- Firebase integration
- Responsive design

## 🚀 Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express
- **Database:** Firebase Firestore
- **Authentication:** Firebase Auth
- **File Storage:** Firebase Storage
